## Hi, I'm Kautsar Albana

Jakarta, Indonesia · open to work

### About me

I build mobile apps with Flutter and Dart, mostly around video playback, live streaming, and third-party SDKs like Amazon Chime, Zoom, and BytePlus.

Outside work I mod Skyrim SE/AE: SKSE plugins in C++, Python tools that patch plugins to work together, and fixes for mod managers so they run on macOS. That last part turned into a habit of porting Windows-only tools to the Mac.

I used to run Arch with i3wm. The dotfiles are still here.
